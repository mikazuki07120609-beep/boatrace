# 水面ノート

全国のボートレースの出走表を毎日自動で更新し、選手のコース別成績とレース場の特徴から「展開の見立て」と解説文を作るサイトです。買い目は出しません。

公開ページ: https://mikazuki07120609-beep.github.io/boatrace/

## しくみ

1. GitHub Actions(`.github/workflows/update.yml`)が毎日 0:20・7:10・17:10(日本時間)に動きます。
2. 公式が配布している番組表・競走成績のファイルをダウンロードして読み取り、`data/program/`・`data/results/` に保存します(`scripts/update.py`)。
   - 過去の成績は、公式サーバーに負担をかけないよう1回10日分ずつ、直近1年分まで取り込みます。10日より前の成績は、集計に使う項目だけに縮めて保存します。
3. 成績から選手のコース別成績と戦法の傾向(直近1年: 勝ったときの決まり手、1コースで負けたときの決まり手)と、レース場のコース別成績(直近90日)を集計し(`scripts/stats.py`)、ページを作ります(`scripts/build_site.py`)。
4. できたページを GitHub Pages で公開します。

各レースのページには「1周1マーク展開ビュー」(`site/assets/turn1.js`)があります。展開の見立てで上位の決着パターンをもとに、選手の平均ST・モーター・コースごとの勝ち方から、スタートして全艇が1周1マークを回り切るまでを上空から見たシミュレーションとして描きます。動画として保存・共有もできます。

## 手元で動かす

```
python3 scripts/update.py            # 公式ファイルをダウンロードして作る(lha が必要)
python3 scripts/update.py --offline  # data/raw にあるテキストだけで作る
```

できあがったサイトは `_site/` に出力されます。

## 注意

- 非公式のサイトです。データの読み取りに誤りが含まれる可能性があります。正確な情報は主催者発表のものをご確認ください。
- 展開の見立ては過去の成績をもとにした目安で、舟券の購入をすすめるものではありません。舟券の購入は20歳以上に限られます。
- レース場データの初期値(`data/stadiums.json`)は BOAT RACE オフィシャルウェブサイト「ボートレース場データ」より。成績が十分たまると、当サイトの集計に切り替わります。
